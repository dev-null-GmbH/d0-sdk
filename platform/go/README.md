# Platform Go machine SDK

`NewMachineClient` binds the shared OAuth/DPoP transport to a fixed production or test Platform resource. Use separate client IDs and keys for each profile. The test profile permits only isolated domain/DNS operations. Callers pass contexts to all methods; generated models retain exact int64 minor-unit prices.

Run `go run ./examples/fixture` for a complete offline domain/DNS flow in both profiles. `go test -race ./...` checks the profile allowlist, audit cursor, required cluster key, and error boundary.

The local shared-auth module replacement is for source qualification and must be replaced by an immutable published module before release.
