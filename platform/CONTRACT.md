# Platform machine SDK contract

The canonical sources are `api/openapi.yaml` (production) and `api/test-openapi.yaml` (customer test). `extract.go` pins their SHA-256 digests, filters to `/platform/v1/` operations with `platform-*` operation IDs, removes human bearer auth, and retains only referenced schemas. It emits `spec/production.json` and `spec/test.json`; `generate.py` pins those digests and emits the Go, TypeScript and Python named operation surfaces. The repository-pinned `oapi-codegen` v2.8.0 creates the Go typed transport models. Run `./sdk/check.sh` to regenerate and qualify all three SDKs; generated drift fails the check.

The production profile has 30 machine operations. The customer test profile is a strict five-operation allowlist: list/get domain and list/upsert/delete DNS records. It uses `https://api.test.d0.eu/platform`, distinct client credentials and isolated synthetic data. All methods use the shared d0-auth OAuth/DPoP transport with fixed resource and `/v1` target; the SDKs never accept an arbitrary API origin. Production-only operations fail before network access in the test profile. Go uses `int64` for minor-unit cents, Python uses `int`, and TypeScript returns exact decimal strings for `*_cents` response fields. The TypeScript parser rejects unsafe integers in all other fields.

`listAuditEvents` exposes the server's exclusive `next_before` cursor; `WalkAuditEvents`/`walkAuditEvents`/`walk_audit_events` bound traversal. The generic `Wait`/`waitFor`/`wait_for` helpers bound asynchronous read polling to two minutes and accept cancellation. Cluster actions require the contract's `Idempotency-Key`; the SDK validates it before egress, and callers must reuse the same key for retries. The canonical Huma header models and generated OpenAPI now mark it required, matching the existing server guard. The server contract omits that header for other writes, including DNS mutations; callers must not assume those operations are replay-safe. `callWithResponse`/`call_with_response` and Go generated response objects expose ETag and request ID per request. Errors carry only bounded status/problem metadata and never the raw response body.

The Go module path targets `github.com/dev-null-GmbH/d0-sdk/platform/go`. The shared auth Go module is locally replaced for qualification. TypeScript and Python use local path overrides for the same reason. The three packages are **not published**. Release assembly must replace local auth paths with immutable published artifacts and run this gate against the exact release tree. No example sends a live request; all examples use the SDK with an offline fixture transport for both profiles.
